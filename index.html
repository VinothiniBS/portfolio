PROJECT 01 / 04
Data Engineering · Orchestration

Dublin Bikes Data Pipeline

An end-to-end pipeline that ingests live Dublin Bikes station data every 15 minutes, transforms it into tested, analysis-ready tables, and surfaces availability and station-health insights through the interactive dashboard alongside.

How it works
  • JCDecaux API ingestion into BigQuery on a 15-minute schedule, orchestrated with Airflow running in Docker
  • dbt raw to staging to marts model layering, with 14 automated data-quality tests
  • Looker Studio dashboard surfacing live station availability and health metrics
Outcome

A cluster of north-city stations sits empty over 50% of the time while south-quay stations jam full - a clear rebalancing signal for the operator, not just a capacity problem.
